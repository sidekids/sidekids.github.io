SideTube

Setting up the family's YouTube key

Optional, free, about ten minutes.

Why

With the family's own free YouTube key, SideTube can find channels by @-address and search cleanly through the official YouTube Data API and has a fallback when YouTube does not deliver the public feed. The key is optional; without it SideTube works as before.

What changes: Requests with the key go to Google and can be linked to the Google account that owns the key. The key itself stays on the iPhone in the operating system's protected storage (keychain), is not backed up and is removed when the app is deleted. Details are in the privacy policy.

What is needed

  • A Google account of the parents (not a child's account).
  • About ten minutes and, ideally, a computer.
  • SideTube on the iPhone with the parent area unlocked.

Step by step

Google changes labels and layout of its console from time to time; the sequence stays the same in substance.

  1. Open the Google Cloud Console (console.cloud.google.com) and sign in with the parents' account. Accept any terms it asks for.
  2. Create a new project, for example "SideTube Family".
  3. Enable YouTube Data API v3: "APIs & Services" → "Library" → search "YouTube Data API v3" → "Enable".
  4. Create an API key: "APIs & Services" → "Credentials" → "Create credentials" → "API key". The key appears and can be copied.
  5. Restrict the key (important: without a restriction the console warns that the key can be used with any application). Open the key by its name. There, select the "YouTube Data API v3" under the API restrictions and, below it under application restrictions, choose "iOS apps" and add the bundle ID xyz.steier.sidetube. Finally "Save". Google points out that restricting to an app alone can be bypassed; that is why the restriction to this one API belongs with it, and usage should be checked in the console now and then. According to the console it can take up to 5 minutes for the settings to take effect. The blue notice "Service account required" concerns other Google services (such as Gemini) and does not apply to the YouTube Data API. Labels can differ slightly depending on the console language.
  6. Get the key to the iPhone: for example by message or note to oneself, and copy it there. Delete the message afterwards; the key does not belong in chats or public places.
  7. Paste it into SideTube: menu (⋯) → "YouTube key (optional)" → "Paste key". SideTube checks it with a test request to Google and only saves it once Google accepts it.

If something does not work

  • "That does not look like a YouTube key": The text is too short or too long or contains spaces and special characters. Copy the key again; it has about 39 characters and usually starts with "AIza".
  • "Google rejects the key": The key was copied wrongly or has been deleted.
  • "YouTube Data API v3 is not enabled": Repeat step 3 in the same project the key was created in.
  • "Blocked for this app": The iOS apps restriction is missing the bundle ID xyz.steier.sidetube or has it spelled wrongly. Wait up to 5 minutes after saving.
  • "Daily quota is used up": See below; it works again the next day.

Quota

According to Google's documentation (page dated 15 October 2026) the default is 10,000 units per day. A lookup of channels, videos or playlist items costs 1 unit each; search is additionally limited to 100 calls per day. The quota resets at midnight Pacific time. For a family this is usually enough, but there is no guarantee, and Google may change the values.

Removing it

In SideTube, tap "Remove key" under "YouTube key (optional)"; the key is deleted from the device. To switch it off entirely, also delete the key or the project in the Google Cloud Console.

Key passed on by accident? On the key's detail page, "Rotate key" creates a new one; the old one becomes invalid afterwards. Paste the new key into SideTube again.
